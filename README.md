# 🏮 城市记忆盲盒（AI + 手势识别网页）

> 以赛促学 · 技术赋能文化创意 · 3 人小组课程作业
> 打开网页 → 登录 → GPS 定位城市 → 手势抓取 → 考古清理 → AI 讲故事 → 收藏图鉴 → 纪念卡分享

**🔗 在线体验：<https://strive886.github.io/city-memory/>**（推荐 Chrome / Edge，手机电脑均可）

## ✨ 这是什么

一个以「城市文化探索」为核心的互动网页：用户通过 GPS 定位到城市，用**手势隔空抓取**本地的「城市记忆盲盒」，解锁一件老物件——先像考古学家一样**挥手擦去泥沙**让它重见天日，再由 **AI 记忆讲述人**生成 80 字城市记忆故事并语音朗读，支持多轮对话提问。收藏进图鉴、点亮成就、生成带真二维码的数字纪念卡分享给好友接力。

首批开通 **石家庄、正定** 两座城市、8 件考据过出处的老物件。

## 🎮 核心流程

```
登录 → GPS定位/选城市 → 手势抓取(握拳) → 考古清理(挥手擦泥)
     → AI讲故事/多轮对话 → 收藏图鉴 → 成就墙 → 纪念卡分享 → 个人中心
```

## 🧩 功能模块

| 模块 | 实现 |
| :--- | :--- |
| 账号体系 | 手机号注册/登录、微信一键登录（模拟）、修改密码、本地会话 |
| 定位与城市 | 浏览器 Geolocation 就近匹配、手动切换城市 |
| 手势交互 | MediaPipe Hands 21 关键点：握拳抓取 / 挥手擦泥清理 / 双手拉开讲故事 |
| AI 与对话 | 城市记忆讲述人：80 字故事 + 多轮问答（知识库注入，可配置 DeepSeek API） |
| 收藏与图鉴 | 图鉴收集、隐藏故事、成就墙（破尘初见 / 打破砂锅 / 城市通） |
| 分享与社交 | 纪念卡册（多卡切换）、Canvas 纪念卡 + 真二维码、收集战报图、好友接力链接 |

## 🛠 技术栈

- **手势识别**：MediaPipe Hands（CDN）+ getUserMedia，21 关键点实时判定
- **AI 智能体**：DeepSeek API（可配置，`js/ai-config.js`）/ 本地知识库兜底，轻量 RAG
- **语音合成**：浏览器内置 SpeechSynthesis（中文）
- **图形生成**：Canvas 绘制纪念卡与收集战报，qrcode-generator 生成真二维码
- **数据存储**：localStorage 全本地模拟（账号 / 收藏 / 记录 / 成就 / 卡册）
- **定位**：浏览器 Geolocation + 球面距离就近匹配

## 🚀 本地运行

```bash
git clone https://github.com/strive886/city-memory.git
cd city-memory
python -m http.server 8000    # 或用 VS Code Live Server / 直接双击 index.html
```

浏览器打开 `http://localhost:8000/index.html`。手势识别首次使用需联网加载组件；无摄像头环境可用页面内「演示按钮」完整体验。
